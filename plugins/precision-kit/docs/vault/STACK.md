# STACK - Framework Versions

> What the project runs on, at which versions, and how to build it.

## Decisions (why these choices)
- Python 3.11+ standard library only: runs everywhere Claude Code runs, nothing to install; tomllib needs 3.11.
- Claude Code plugin format (skills/, hooks/hooks.json, .claude-plugin/): one install gives skills and hooks.
- Repo root is plugin + marketplace (source "./"): `/plugin install precision-kit --marketplace osmanITGR/precision-kit`.
- Shared scripts live once (detect_stack.py, verify.py ...); package_skills.py bundles copies into claude.ai zips.

## Upgrade policy
No runtime dependencies. GitHub Actions versions in CI are reviewed when CI changes (ci-setup).

## Commands
- Tests: `python3 scripts/selftest.py` (Python 3.11 and 3.13 in CI)
- Plugin validation: `claude plugin validate .`
- claude.ai zips: `python3 scripts/package_skills.py`
